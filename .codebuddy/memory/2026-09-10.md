## AdSense 预检报告「找不到隐私政策」根因分析（docs/Ads/问题/审查1.md）

- 结论：隐私政策页面存在且正常（`/privacy` 200、含 Cookie 披露、含 AdSense 脚本、已进 sitemap）；Footer 组件也有 `/privacy`、`/terms` 链接（zh-CN.json 的 `footer.nav.legal.links` + `footer-legal` 两处）。

- 验证：线上 `https://qingzao.site/` 原始 HTML 仅 4812 字节，`隐私` 出现 0 次，`class="footer"` 出现 0 次；`/privacy` 页面同样无 footer。检测工具报「首页 538 词」与静态片段规模吻合，说明它取的是未执行 JS 的 HTML。
- 附带发现：`buildStaticBodyHtml('/')` 仍在渲染**旧版工作室首页**文案（hero/products/about/contact），而 `App.jsx` 的 HomePage 早已改为 BlogHero/ReadingEntries/FeaturedSeries/CategoryBrowse/LatestPosts，静态内容与运行时内容已漂移。

同一道知乎题「为什么中国人把客厅弄那么大、厨卫那么小」分别用 `elon-musk-perspective` 与 `luo-yonghao-perspective` 两个 skill 作答（用户手动切换）。已核实的共用事实底稿，后续写装修/户型类内容可直接复用：

- **GB 50096-2011《住宅设计规范》下限**：双人卧室 ≥9㎡、单人卧室 ≥5㎡、兼起居卧室 ≥12㎡、起居室（厅）≥10㎡、厨房 ≥4㎡（小套型 3.5㎡）、卫生间（三件洁具集中）≥2.5㎡——2011 修编时**从 3㎡ 降到 2.5㎡**。
- **90/70 政策**（2006 国六条）：新开工商品住房中套型 90㎡ 以下需占项目总面积 70% 以上；2024 年起上海、深圳等地陆续松绑。这是中国户型结构最关键的制度约束。
- **高层得房率 70-80%**（公摊 20-25%）；地价占房价约 20-40%，建安成本约 25-35%，开发利润 8-15%。
- **酒店对比**：经济型客房 15-20㎡、卫生间 3.5-4.5㎡ → 占比 20-25%；而住宅 90㎡ 里卫生间约 3㎡ → 占 4.4%。酒店相对占比是住宅的 5 倍左右。整体卫浴（装配式）规格源自日本体系：1216=1.92㎡、1616=2.56㎡、1620=3.2㎡。
- **电视开机率** 2016 年 70% → 2025 年不足 30%；2025 年国内彩电销量 2763 万台，近十年新低。可用于支撑「客厅功能被抽空」的论据。
- 淋浴间的物理下限推算：0.9m×0.9m ≈ 0.81㎡（肩宽 0.45m + 抬手作业包络约 0.85m）。
