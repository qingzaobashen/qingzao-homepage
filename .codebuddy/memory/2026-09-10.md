# 2026-09-10

## AdSense 预检报告「找不到隐私政策」根因分析（docs/Ads/问题/审查1.md）

- 结论：隐私政策页面存在且正常（`/privacy` 200、含 Cookie 披露、含 AdSense 脚本、已进 sitemap）；Footer 组件也有 `/privacy`、`/terms` 链接（zh-CN.json 的 `footer.nav.legal.links` + `footer-legal` 两处）。
- 真正根因：**预渲染的静态 HTML 里没有 Header/Footer**。`scripts/prerender.mjs` 的 `buildStaticBodyHtml()` 只往 `#root` 注入手写正文片段（`static-prerender`），`buildPostHtml()` 同样只有面包屑。因此任何页面的原始 HTML 都没有导航栏和页脚 → 不执行 JS 的抓取工具看到的首页只有正文，没有任何指向隐私/关于/联系的链接。
- 验证：线上 `https://qingzao.site/` 原始 HTML 仅 4812 字节，`隐私` 出现 0 次，`class="footer"` 出现 0 次；`/privacy` 页面同样无 footer。检测工具报「首页 538 词」与静态片段规模吻合，说明它取的是未执行 JS 的 HTML。
- 附带发现：`buildStaticBodyHtml('/')` 仍在渲染**旧版工作室首页**文案（hero/products/about/contact），而 `App.jsx` 的 HomePage 早已改为 BlogHero/ReadingEntries/FeaturedSeries/CategoryBrowse/LatestPosts，静态内容与运行时内容已漂移。
- 修复方向：在 `prerender.mjs` 中为所有静态路由与博客页统一注入共享的 `<header>`/`<footer>` 静态片段（至少含隐私政策、服务条款、关于、联系链接），并同步更新首页预渲染文案。

## 已实施修复（同日）

- `scripts/prerender.mjs` 新增 4 个函数：`localeHref(path, locale)`、`buildSiteHeaderHtml(locale)`、`buildSiteFooterHtml(locale)`、`withSiteChrome(bodyHtml, locale)`。页头/页脚复用 Header.jsx / Footer.jsx 的真实 class（`header`/`header-inner`/`header-logo`/`header-nav`/`footer`/`footer-group` 等），避免 hydration 前无样式闪烁。
- `writeRoute()` 中 `bodyHtml` 改为 `withSiteChrome(bodyHtml, chromeLocale)` 包裹（`locale==='en'?'en':'zh'`），静态路由与博客页全部生效。
- `buildStaticBodyHtml('/')` 重写为**博客首页**内容（home.heroEyebrow/blogTitle/blogSubtitle + readingEntries + featuredSeries + categories + 最新 6 篇 posts + viewAllPosts），替换掉旧的工作室介绍文案，消除静态/运行时内容漂移。
- 验证：`npm run build:full` EXIT=0；dist/index.html 4812→6188 字节，`href="/privacy"` 2 处、`/terms` 2 处、含 `/about` `/contact`；dist/en.html 含 `/en/privacy` 2 处；dist/privacy.html 与 dist/blog/*.html 均含 footer。本地 preview 冒烟 200，h1 为「青枣笔记」，AdSense 脚本仍在。
- 注意：英文首页产物路径是 `dist/en.html`（`'/en'.slice(1)`），不是 `dist/en/index.html`。
