## 1. 品牌定位

**Slogan**：青枣笔记 —— 装修经验、独立开发与生活思考

**内容方向**：
- **生活笔记**（主线）：装修指南、家居经验、避坑手册
- **开发 / 独立产品 / AI**（辅线）：技术分享、产品思路、工具评测

**目标用户**：装修中的业主、独立开发者、效率工具爱好者

## 2. 设计 Token

### 2.1 色彩系统

| Token | 色值 | 用途 |
|-------|------|------|
| `--color-bg` | `#F7F4EE` | 宣纸白，页面背景 |
| `--color-ink` | `#1F1F1F` | 墨色，正文 |
| `--color-primary` | `#5B7C6D` | 青绿，主色调 |
| `--color-accent` | `#8B3A3A` | 枣红，强调色 |
| `--color-border` | `#D9D2C3` | 淡灰褐，边框/分割线 |
| `--color-muted` | `#8C8C8C` | 灰色，辅助文字 |
| `--color-canvas` | `#FFFFFF` | 纯白，卡片背景 |
| `--color-hover-bg` | `#EDE8DE` | 极淡宣纸，hover 态 |

### 2.2 字体系统

| 用途 | 字体 | 字重 |
|------|------|------|
| Logo | 霞鹜文楷 / 方正清刻本悦宋 / 思源宋体 Heavy | Heavy |
| 文章标题 | 思源宋体 / Noto Serif SC | SemiBold |
| 正文 | 思源宋体 / Noto Serif SC | Regular |
| 英文 | IBM Plex Sans | — |
| 代码 | JetBrains Mono | — |

### 2.3 间距与尺寸

- 基础单位：`4px`
- 正文行高：`1.8`
- 正文最大宽度（文章）：`700px`
- 文章卡片圆角：`4px`（极轻微）
- 边框：`1px solid #D9D2C3`

### 2.4 阴影

- 卡片阴影：极淡，`0 1px 4px rgba(0,0,0,0.04)`
- hover 阴影：`0 4px 12px rgba(0,0,0,0.06)`

## 3. 布局结构

### 3.1 首页

```
┌───────────────────────────────────────────┐
│  Header (固定)                              │
│  青枣  │  笔记  系列  关于  │  🔍  EN      │

│  「青枣笔记」                              │
│  装修经验、独立开发与生活思考                │
│  (装饰元素：印章或笔触)                     │
├───────────────────────────────────────────┤
│  精选系列 (3列)                            │
│  ┌─────┐ ┌─────┐ ┌─────┐                  │
│  │系列1 │ │系列2 │ │系列3 │                  │
│  │N篇   │ │N篇   │ │N篇   │                  │

│  Footer                                    │

└───────────────────────────────────────────┘
```

### 3.2 文章列表页（/blog）

- 顶部：页面标题 + 分类筛选（印章风格标签）
- 文章卡片：左侧青绿竖线装饰，淡灰褐边框
- 卡片内容：日期 → 分类标签（印章风格）→ 标题 → 摘要 → 标签 → 阅读全文

### 3.3 文章详情页（/blog/:slug）

- 顶部：阅读进度条（1px 青绿线，粘在 Header 下方）
- 面包屑：首页 / 笔记 / 文章标题
- 正文区：窄栏居中，max-width 700px
- 正文样式：
  - H2：思源宋体 SemiBold，下方 `1px solid #D9D2C3` 分割线
  - H3：思源宋体 SemiBold
  - 段落：行高 1.8
  - 引用：左侧 3px `#5B7C6D` 竖线，楷体/斜体
  - 代码行内：`#EDE8DE` 背景，JetBrains Mono
  - 代码块：深色底（`#2C2C2C`），JetBrains Mono
  - 表格：极简边框，表头 `#F7F4EE` + `#5B7C6D` 文字
  - 图片：居中，圆角 4px，最大宽度 100%
- 底部：上一篇 / 下一篇（青绿箭头）+ 系列内文章导航 + 评论

### 3.4 系列页（/series）

- 列表页：每个系列一张"卷轴"风格卡片
- 详情页：系列标题 + 描述 + 文章列表（带序号，按建议阅读顺序排列）

### 3.5 关于页（/about）

- 简洁的个人介绍页
- 东方风格排版，类似"自序"

## 4. 组件规范

### 4.1 Header

- 高度：`64px`
- Logo：霞鹜文楷，`#5B7C6D` 青绿色
- 导航：思源宋体 Regular，`#1F1F1F`
- 激活态：下方 `2px` 枣红线
- 滚动态：加 `background: rgba(247,244,238,0.95)` + 底部 `1px solid #D9D2C3`
- 移动端：汉堡菜单，从右滑入

### 4.2 文章卡片

- 边框：`1px solid #D9D2C3`
- 左侧装饰：`3px solid #5B7C6D`（青绿竖线）
- 内边距：`24px`
- 标题：思源宋体 SemiBold
- 日期：`#8C8C8C`，小字
- 标签：印章风格，`1px solid #8B3A3A`，`#8B3A3A` 文字，透明背景
- hover：`box-shadow` 加深，轻微上移

### 4.3 系列卡片（首页）

- 右侧装饰：`4px solid #8B3A3A`（枣红竖线，仿古书函标签）
- 标题：思源宋体 SemiBold
- 文章数："共 N 篇"，灰色
- CTA："从第一篇开始 →"

### 4.4 阅读进度条

- 位置：Header 底部，`position: fixed`
- 高度：`2px`
- 颜色：`#5B7C6D` 青绿
- 逻辑：`(scrollTop / (scrollHeight - clientHeight)) * 100%`

### 4.5 分页

- 使用"加载更多"按钮，而非页码
- 按钮样式：青绿边框 `1px solid #5B7C6D`，hover 填充 `#5B7C6D` 背景 + 白色文字

### 4.6 印章标签（分类/标签）

```css
.seal-tag {
  display: inline-block;
  padding: 2px 12px;
  border: 1px solid #8B3A3A;
  color: #8B3A3A;
  background: transparent;
  font-size: 12px;
  letter-spacing: 0.5px;
}
```

## 5. 交互细节

- 所有链接 hover：颜色过渡 `0.2s ease`
- 卡片 hover：`transform: translateY(-2px)` + 阴影过渡
- 移动端菜单：slide-in 动画，`0.3s ease`
- 文章加载：内容 fadeIn 动画
- 分类筛选：平滑过渡

## 6. 响应式断点

| 断点 | 布局调整 |
|------|---------|
| > 1024px | 三列系列，两列文章 |
| 768px - 1024px | 两列系列，单列文章 |
| < 768px | 单列全部，Header 汉堡菜单 |
