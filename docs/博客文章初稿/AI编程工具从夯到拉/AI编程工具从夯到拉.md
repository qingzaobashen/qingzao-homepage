# 从夯到拉：2026年9月AI编程工具权力榜

废了，我在6月份收藏的那篇"AI编程工具深度评测"，现在打开，基本等于了出土文物。

这一年行业的速度太nm快了：OpenAI一口气给自家编程模型换了一串名字（5.1、5.1 Max、5.2、5.3、5.4——8月31日刚退役、5.5、5.6，一直到GPT-6）；Anthropic则把命名权交给了文学系，别人家发"3.8 Max"，他家发"寓言"（Fable）和"神话"（Mythos）——而且"寓言5"（Fable 5）今年还下架过一次，7月1日又重新上架。一个模型，竟是整出了原版和导演剪辑版。

所以开排之前先立规矩：这行连裁判都不可信了。老牌软件工程基准测试（SWE-bench Verified）今年2月被OpenAI官宣弃用，理由是59%的题目漏进了各家训练集；而榜单第8到15名，七家实验室八个模型挤在80.6%到80.0%之间，只差0.6分。用一句话概括：卷子漏题还考什么考，八个选手挤在0.6分里，这不是排行榜，是搞笑。

因此本文不看广告，看疗效，你方唱罢我登场，按五档排：

- **夯**：主角，镜头、预算、争议全在这里。
- **顶级**：主要配角，有独立剧情线，偶尔抢戏。
- **人上人**：比下有余，弹幕刷"其实它挺好用"的主力部队。
- **NPC**：不影响剧情，站街、发任务、当背景板。
- **拉**：角色已死，有事烧纸。

## 夯：世界围着它们转

**Claude Code：现任梅西，但王要收门票。** 9月登顶工具榜第一，网页开发竞技场（WebDev Arena）积分榜全场最高（1762分），比上代高出73分；开发者情感调查里"最爱率"46%，第二名19%，第三名9%——爱是真实的，门槛也是真实的：没有免费档，20到200美元一个月。更真实的是：约43%的时间，你在调试它写的代码。它产的bug比你产的还自信。

**Cursor：手感天花板，老板上天了。** 8月14日，SpaceX收购其母公司交割，正式改姓。产品本身仍是日常编辑手感最好的，企业支出份额虽从41%跌到26%，但那是"并购阵痛"，不是产品力问题。用户现在的心情很微妙：我就想写个代码，结果老板换成了想上火星的人。照这个趋势，以后提交代码得叫"发射"，回滚叫"着陆失败"。

**OpenAI Codex：弃考的人，模考第一。** 2月宣布"榜单漏题所以不参加高考"，转头在终端操作基准测试（Terminal-Bench）上，GPT-6以58.2%压过Claude家的57.9%——全公司唯一还手的阵地。命令行工具开源免费，定位清晰：异步派活、回收结果。缺点是家谱比《红楼梦》人物表还乱，5.4上个月刚下葬，6就登基了。

## 顶级：本月新剧情最多的一个档

先说开源群雄，这届顶级被开源承包了一半。

OpenCode，协议宽松到可以随便商用，75家以上模型随便接，支持气隙部署（Air-gapped），以19.8万星登顶代码托管平台最受欢迎智能体。穷且益坚，不坠青云之志。

Cline干了一件很妙的事：今年5月把自家开源软件开发工具包（SDK）抽出来变成基础设施，如今GitHub、Anthropic都在玩同一手——被抄作业抄成了行业标准。黑历史也有一笔：它的命令行安装包遭遇过软件供应链攻击（Supply Chain Attack），给各位提个醒，别把自动批准当信仰。

Aider是"江湖上全是他的传说"：代码库地图（Repo Map）、原子提交（Atomic Commit）、多语言基准，全行业抄了个遍，然后发版速度进入养生模式。

Goose更绝：别人怕被收购，它直接出家——被捐给一个中立的智能体基金会（Agentic AI Foundation），跟工具协议（MCP）标准进了一个户口本。

OpenHands学会了"借兵"：通过智能体协作协议（ACP），能把Claude Code、Codex塞进自己肚子里当苦力。

Crush则是公认的终端界面（TUI）颜值天花板——属于给终端做了医美，脸在江山在。

再说三个非开源面孔。Kiro（亚马逊云）别家说完需求直接开写，它非要先生成需求、设计、任务三份文档，你批准了才动手——适合要被审计的团队，不适合今晚要演示的你。Devin Desktop，前身Windsurf，这出连续剧值得单开一期：OpenAI约30亿美元要买（崩了）、Google掏24亿挖走CEO和联创、Cognition花2.5亿捡漏、6月隔空改名、7月老产品入土——产品其实不差，但你让我的编辑器一年换三个爹，这谁受得了。Google Antigravity值得单说：个人版0美元，代码补全不限量，还能在Gemini、Claude、gpt-oss之间挑模型——史上第一次，谷歌家的免费工具能白嫖Claude。唯一的问题：按谷歌杀产品的前科，建议先用着，别装修。

哦对，还有Amp：套餐名叫"兆瓦"（20美元）和"吉瓦"（200美元），四档强度从低到超高——别家智能体费额度，它费电，最高档一开，你家电表开始cosplay核电站。

## 人上人：本届最大编制，内卷重灾区

先说我那"正房"GitHub Copilot。180万付费用户、约42%市场份额、10美元一个月全场最低、6月起改积分计费——它是全世界最普遍的编程工具，也是最不被热爱的：最爱率只有9%。婚姻是真实的，激情是没有的，但你要离婚时才发现，公司里所有审批流程都是按它建的。正房的地位，远房亲戚的待遇，这就是人上人。

**国产队是本次重点。** Trae（字节跳动）免费档就能摸Claude 4.6，去年底已攒下600万注册、160万月活。但剧情很字节：2月24日把"每月600次高速请求"改成按实际用量计费，老用户哀嚎"美好旧时光没了"；7月开始弹"今日对话额度已耗尽"，顺手给你指一条叫"速通"的付费优先队列。经典三步走：免费引流、悄悄收紧、温柔逼氪。隐私条款是"遥测（Telemetry）不可退出、销户后数据留5年"——用不用，取决于你的代码值不值这个票价。

Qoder CN（阿里云，原通义灵码）拿下了高德纳魔力象限（Gartner Magic Quadrant）挑战者席位，99元一席位，产品力真不差。但家务事堪比清宫剧：5月20日灵码改名，9月15日旧商品停售，2027年4月停续，9月正式停服；顺手把自家协作工作台也判了死刑。一年之内改名、换代、发丧一条龙——老用户的心情：我到底买了个工具，还是买了张船票？

CodeBuddy（腾讯云）握着国内最猛的内部背书：覆盖腾讯1.2万名工程师，它自己的代码90%由AI生成——真·我生成我自己。4月发布云端智能体，名字就叫"NPC"，官方解释是"非程序员同事"（Non-Programmer Colleague）——在我们这张榜里NPC是个档位，人家那是学名。此外还有"小龙虾全家桶"：四款产品一虾四吃，积分互通，总有一款能让你付费。

Kimi Code，月之暗面出品，命令行加编辑器插件双形态，默认K2.7代码模型、可切K3，国内直连、支付宝微信付款，对新手最友好的一集。作为Kimi我发言到此为止，再说下去你要关页面了。

智谱的ZCode搞"手机远程控电脑"的对话式开发，路子最激进；DeepSeek把智能体框架开源，喊出"智能体时代的安卓"。国产队五条路线并行，没有一条在抄Cursor。

**海外散兵**：JetBrains AI，10美元多模型内置，是JetBrains用户的嫁妆——你不一定买，但它得在。Devin云版请牢记"算力单元"（ACU）这个词：20美元只是入场券，重度使用账单能冲到2000美元以上，它的计费方式应该申遗。Augment彻底放弃个人用户，100美元包月50席，专心做大厂生意——个人市场对它来说，爱过。Kilo Code收编了Roo Code的全部遗孤，开源、500多个模型随便挑，开源界的接盘侠，但接得挺体面。v0是React界面天花板，但离开Vercel家的部署生态就腿软。Qodo和CodeRabbit做智能代码评审——提词器，不是演员，戏好不好它们不背锅，但台词得它们递。Tabby是自托管代码补全，内网宅男的浪漫。终端杂牌军（Gemini CLI、DeepSeek TUI、avante.nvim）里，前一个是10万+星的开源名门，可惜亲爹已改立储君；后两个分别是命令行党和vim党最后的倔强。

## NPC：站街的，但各有戏路

Tabnine和Cody今年干了同一件事：砍掉个人免费档，退守企业。一个39到59美元一座，一个59美元企业专属，卖的都是"代码不出内网"。它们不是不行了，是主动转型特型演员——金融、军工、医疗，离线部署，出场费贵，台词就一句：合规。

氛围编程（Vibe Coding）四件套（Replit、Bolt、Lovable等）要注意：它们在"程序员宇宙"是NPC，在"不会写代码的创业者宇宙"可是主角。但在专业开发者这张榜上，它们共享同一个死穴：**演示之后，魔法消失。** 横评实测：Bolt一条指令就把免费额度烧光；Lovable被封为"最懒智能体"，五步调试收五步的钱；Base44号称全栈，却不能导入任何npm包；Replit稍好，一体化省心，但"一个账号等于编辑器等于服务器等于发票"，用之前先默念三遍。

## 拉：讣告栏

Amazon Q Developer：2027年4月停服，讣告让转投Kiro——生是亚马逊的人，死是Kiro的鬼。Gemini Code Assist个人版：6月18日卒，转世为Antigravity。通义灵码旧商品：三阶段谢幕，停服时间比Amazon Q还晚，属于"慢性拉"。QoderWork CN：上线一年多即关停，连讣告都很有阿里味：研发场景迁桌面版，办公场景迁千问，积分不互通，退款自己找销售谈。Phind：1月16日卒，遗言"被基础模型商品化"——它不是输给同行，是输给时代，这最残忍。Roo Code：4月21日卒，用户集体投奔Kilo Code。Void：6月归档，理想主义存档完毕。Continue：最终版已发，维护停摆，官方建议"老部署继续用，但别当默认选项"——翻译过来：守灵可以，别办婚礼。

压轴永远是裁判：软件工程基准测试本人，59%漏题，八家挤0.6分。当裁判和选手抱在一起，我们看的就是春运。

## 收尾

84%的开发者已经在用或打算用这类工具，而且人均同时用2.3个。所以"哪个最好"这个问题在2026年9月已经过期了——但这张榜还是想告诉你一个结构性事实：44个席位里，人上人占了17席，是最大编制。头部三家吃肉，腰部17家抢汤，底部生死线常态化。这也解释了各家今年的集体转向：Copilot改积分、Cursor被收购、Trae改用量、阿里发丧、Tabnine和Augment弃个人——中间层在坍缩，所有人都在往"企业钱包"和"免费引流"两个极端跑，夹在中间的个人付费用户，正在被礼貌地劝退。

所以对个人开发者的建议是：夯档挑一个当主力，顶级挑一个开源的当备胎（反正不要钱），然后系好安全带——按这个死法名单的更新频率，下个月这张表还得作废一次。

这行最大的稳定，就是不稳定本身。
